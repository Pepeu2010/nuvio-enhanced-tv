Telumia modifications: package/class name and constructor injection of the
existing playback MediaSource.Factory, plus a bounded 4 MiB / 1.5 s load-control
budget for preview extraction. The bundled ExoPlayer engine remains
unchanged. The injected factory is necessary because the 1.8.0 API constructs
its own default transport and does not expose per-source HTTP header support.
